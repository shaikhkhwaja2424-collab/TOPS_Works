# Importance of Testing in SDLC (BookMyShow Example)
<br>
<br>
## 1. Requirement Stage
<br>
Testing ensures requirements are clear and complete.
<br>
Example: Verify ticket booking, seat selection, and payment requirements.
<br>
<br>
## 2. Design Stage
<br>
Testing reviews application design before development.
<br>
Example: Verify movie selection and payment flow.
<br>
<br>
## 3. Development Stage
<br>
Developers perform unit testing on individual modules.
<br>
Example: Verify seat booking functionality.
<br>
<br>
## 4. Testing Stage
<br>
Complete application testing is performed.
<br>
Example: Login, booking, payment, and notification testing.
<br>
<br>
## 5. Deployment Stage
<br>
Testing verifies the application in the live environment.
<br>
Example: Verify live payments and booking confirmations.
<br>
<br>
## 6. Maintenance Stage
<br>
Regression testing ensures new updates do not affect existing features.
<br>
Example: Verify ticket booking still works after adding new features.
<br>
<br>
## Conclusion
Testing is important at every SDLC stage because it helps identify defects early, improves software quality, reduces costs, and provides a better user experience.
